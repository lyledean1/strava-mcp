## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Please do not open a public issue for security vulnerabilities.**

Instead, email the maintainer directly at: [MAINTAINER_EMAIL]

You should expect an initial response within 72 hours. Once the issue has been confirmed, a fix will be developed and released as soon as possible.
